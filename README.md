# KTH–LiU Decentralized AI and Computing Workshop

Static GitHub Pages website for the **18–19 November 2026** workshop hosted at **KTH**.

## Contents
- `index.html` — website sections and text
- `styles.css` — visual design and banner background
- `script.js` — mobile navigation

The agenda is deliberately marked **coming soon**. Research themes are suggestions, not a confirmed program. No speakers, registration, or practical venue sections are included.

## Edit
Edit `index.html` to change descriptions, organizers, or the program. To change the hero photograph, replace the image URL in `.hero` in `styles.css` with your own photo, ideally a local `assets/banner.jpg`.

## Publish on GitHub Pages
Upload the **contents** of this folder to the root of a public GitHub repository. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save. The published URL will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
